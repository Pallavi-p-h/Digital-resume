# Digital Resume Website

A Django-based digital resume and portfolio website.

## Features

- Personal profile and biography
- Downloadable CV
- Skills and skill scores
- Certificates
- Portfolio projects
- Blog posts
- Testimonials
- Contact form
- Django admin content management

## Technologies

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap
- Pillow
- Django CKEditor
